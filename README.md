# 📊 Hungry Jack's QSR Operations & Labor Optimization Project

An end-to-end data analytics project using Python to generate operational data, MySQL for data engineering/ETL, and Tableau to build an interactive business dashboard.

## 🛠️ Tool Stack
* **IDE:** VS Code
* **Programming:** Python (Pandas, NumPy)
* **Database:** MySQL
* **Visualization:** Tableau Public

## 📈 Dashboard & Code
* **Interactive Tableau Dashboard:** [https://public.tableau.com/app/profile/akshesha.patel/viz/shared/FMH52ZQ4W]

## 💡 Key Business Recommendations
* **Labor Allocation:** Moved 2 operational roster hours from slow Monday mornings to late-night weekends to resolve drive-thru speed bottlenecks.
* **Targeted Training:** Identified a 35% speed-of-service delay during Thursday lunch rushes, flagging a specific crew execution/coaching opportunity.
